# ADR-0025：米家 `miIO.sub` 局域网推送

- 日期：2026-11-24
- 状态：Proposed

## 背景

深度调研确认，部分米家 Wi‑Fi 设备支持 `miIO.sub`。设备探针返回 `MSUB`/`PUB` 且 wildcard 为 `0xFE` 时，客户端可以发送 `miIO.sub` 并接收 `properties_changed` 与 `event_occured`。订阅需要持续连接、ACK、重复消息抑制和保活状态机，设备型号支持范围并不统一。官方默认关闭该能力。

## 决策

本阶段不实现 `miIO.sub`。米家云场景列表和执行继续使用现有加密云会话，局域网通道保持现有请求/轮询实现。后续实现必须独立评估并经过新的安全与网络传输审查。

## 待确认问题

- 探针字段、wildcard 和 sub_type 在不同固件上的兼容范围。
- 常驻 socket 的生命周期、睡眠/网络切换恢复和订阅撤销语义。
- 入站事件的设备身份校验、ACK 重放与 5 秒去重策略。
- 明文局域网端点、凭据边界和用户可见的隐私/网络开关。
- 轮询与推送同时存在时的状态合并、乱序事件和离线判定。
