# v1.5.0 真机冒烟清单

发版前在真机上逐项过一遍。每项只看「能用、没回归」，大约 30–40 分钟。失败项记下现象和截图，先不要打 tag。

## macOS

### 面板与焦点（#474 #491 #521）
- [ ] 前台开着编辑器或视频时按 `⌥M` 呼出面板：前台窗口标题栏不变灰
- [ ] 面板里直接打中文（输入法候选框正常）、按 `Esc` 关闭
- [ ] 首屏只有三层，点「快捷」胶囊或按 `⌘K` 能展开推荐和场景，重开后保持上次状态
- [ ] 设置 › 安全与提醒 › 打开「共享屏幕时隐藏面板与摄像机窗口」，开会议共享屏幕后对方看不到面板

### 高危控制（#498）
- [ ] 热水器类设备：长按 0.65 秒圆环走满才执行；中途松手什么都不发生
- [ ] 阀门或车库门：要滑轨拖到底才执行
- [ ] 用键盘或 VoiceOver 操作同一设备：仍弹确认框

### 快捷键与提示（#505 #521）
- [ ] 给一盏灯绑全局快捷键：在别的 App 里按下能开关，右上角提示出现在鼠标所在的屏幕
- [ ] 给一个高危设备绑快捷键：按下仍要确认

### 自动化（#486 #501 #503 #500 #502）
- [ ] 新建「每天某时刻」规则，等到点执行一次
- [ ] 新建 Wi-Fi 规则时能填网络名称
- [ ] 「开会」模板：选一盏灯，打开摄像头时灯亮，关闭摄像头后灯恢复原状

### 网络与可靠性（#477 #484 #494 #479 #516）
- [ ] 合盖睡眠 5 分钟后打开：HA 设备几秒内恢复
- [ ] 切换 Wi-Fi 或开关 VPN：几秒内重连
- [ ] 拖亮度滑块：松手后不回弹
- [ ] HA 用自定义域名时照常连上

### 摄像机（#490 #493）
- [ ] 静音看画面时蓝牙耳机不切成通话音质；点开声音后能听到
- [ ] 门铃开启「自动弹出」后按门铃：右上角小窗带倒计时，鼠标碰一下就不再自动关

### 只读通用摄像机（#529 #531）
- [ ] 设置 › 家居连接 › 高级连接选项 › 添加通用摄像机（RTSP 或 ONVIF，局域网地址）：「测试连接」出画面，保存后出现摄像机卡片，能开小窗和画中画
- [ ] 填一个公网地址：保存或测试前要求确认
- [ ] 删除该摄像机后卡片消失；钥匙串访问里 `generic-camera:` 条目同步删除

### 氛围与群控（#511 #523 #532）
- [ ] 「保存当前为氛围」后改乱灯光，再应用氛围能恢复；撤销可用
- [ ] 含窗帘或车库门的氛围：用快捷键应用后立即撤销，开合位置回到应用前
- [ ] 房间顶部群控胶囊能一键开关同类灯；对助手说「关掉客厅所有灯」时先出现预览，确认后才执行

### 磁贴点击、动效与文案（#533 #534 #535）
- [ ] 有调节项的灯：点图标只开关，点名字展开调节；切换常规/液态玻璃与紧凑模式后规则不变
- [ ] 高危设备的长按圆环和滑轨只在图标上；中途松手圆环平滑退回，不执行
- [ ] 系统设置开「减少动态效果」：面板不再有弹簧和缩放，长按圆环仍能看到进度
- [ ] 面板底部没有退出按钮；「更多」菜单里仍能「退出 MenuBarHome」
- [ ] 浅色与深色各开一次面板，分段控件滑块、箭头旋转、数字变化不闪不跳

## Windows 11

### 托盘与外观（#472 #485 #489 #496）
- [ ] 多显示器且缩放比例不同：面板位置正确，不在 Alt+Tab 里出现
- [ ] 任务管理器禁用开机自启后，应用设置里的开关如实显示为关
- [ ] 设置窗是 Mica 材质，强调色跟随系统；首屏「快捷」胶囊和 Ctrl+K 可用

### 连接（#471 #473 #482 #495 #508 #510）
- [ ] 设置里「在局域网中查找」能找到 HA
- [ ] 睡眠唤醒、切换 Wi-Fi 后 HA 和米家几秒内恢复
- [ ] 重启 HA 服务器后，手动点开关能立即重连，无需等待几分钟

### 米家（#478 #515 #517）
- [ ] 局域网可达的米家设备开关延迟明显变低
- [ ] 四路排插「全关」一次生效
- [ ] 拖滑块不回弹、不积压

### 摄像机（#476 #488 #492 #504）
- [ ] 摄像机画面可拖出成置顶小窗，关闭后不残留 go2rtc 进程
- [ ] 静帧墙显示，`%LOCALAPPDATA%\MenuBarMijia\CameraEvents` 不会无限增长

### 只读通用摄像机（#530）
- [ ] 设置里添加通用摄像机（局域网 RTSP/ONVIF）：卡片出现，实时画面可看；退出应用后 `go2rtc.yaml` 里没有密码，没有残留 go2rtc 进程
- [ ] 公网地址需要确认；删除后凭据管理器里的条目一并删除

### 自动化与通知（#487 #514 #524）
- [ ] 摄像头占用触发器能触发；本应用自己的摄像机画面不误触发
- [ ] 告警通知上的「立即关闭」按钮可用；锁屏时被拦截

### 氛围、快捷键、群控（#509 #525 #526）
- [ ] 全局快捷键开关设备；高危设备仍要确认
- [ ] 氛围保存与应用、房间群控（含窗帘）正常

### 磁贴点击与动效（#533 #534 #535）
- [ ] 经典磁贴：点图标开关，点名字展开调节；摄像机点名字仍打开实时画面（见 #539）
- [ ] 全部关闭长按：中途松手进度条退回，再按从零开始
- [ ] 通用摄像机删除要点两次才删
