# v1.4 发版前冒烟清单

只测真机上最容易出事的地方：升级后行为变没变、设备会不会被误控、关掉的功能是否真的停了。每项通过就打勾，不通过记下现象再找我，其余小问题一律记 issue，不挡发版。

## macOS（必测，约 30 分钟）

先用你平时在用的 v1.3.0 实例升级，不要清数据。

- [ ] **1. 升级不变样**：升级后面板里的设备、收藏、排序和升级前一样，米家和 HA 都还连着，没有弹首启引导。
- [ ] **2. 升级不偷开功能**：设置里 Raycast/伴生集成、悬浮球保持升级前的开关状态（原来关的仍是关）。
- [ ] **3. 控制一盏灯**：在面板开、关一盏真实灯，状态 2 秒内跟上。
- [ ] **4. 高风险确认还在**：对窗帘或车库门这类设备操作，仍会弹二次确认；取消后设备不动。
- [ ] **5. 全关不碰窗帘**：点「全部关闭」，灯和插座关掉，窗帘、车库门不动。
- [ ] **6. 定时任务暂停与恢复**：新建一个 2 分钟后的定时，到设置里关掉定时任务功能，定时显示为暂停且到点不执行；再打开，它回到可执行或进入「错过」流程，不会自动补发。
- [ ] **7. 关摄像机类型**：打开一路摄像机实况，再在设备类型里取消摄像机，画面立刻停、活动监视器里没有残留的取流进程；勾回后能重新打开。
- [ ] **8. 设备类型裁剪**：取消一个类型（如风扇），面板和搜索里看不到它，安全告警类传感器仍会提醒；勾回后恢复原位置。
- [ ] **9. 停用一个连接**：停用 HA 连接，HA 设备从面板消失、米家设备照常可控；重新启用后 HA 设备回来。
- [ ] **10. AI 与语音开关**：关掉 AI 一句话控制和语音输入，对应按钮消失、不再请求麦克风；打开后恢复。
- [ ] **11. 锁屏拦截**：锁屏状态下通过 Raycast 或快捷动作发控制指令，被拦下并提示。
- [ ] **12. 新装路径（可选，用新用户账户测）**：首启出现平台选择三卡，跳过后只显示灯和开关预设，没有报错。

## Windows（有机器再测，约 15 分钟）

- [ ] **W1. 升级不变样**：同 macOS 第 1 项。伴生集成保持开启（Windows 旧版就是常开）。
- [ ] **W2. 控制一盏灯**，同第 3 项。
- [ ] **W3. 全关不碰窗帘**，同第 5 项。
- [ ] **W4. 定时任务暂停与恢复**，同第 6 项。
- [ ] **W5. 关摄像机类型**：画面停、任务管理器里没有残留的 go2rtc/ffmpeg 进程。
- [ ] **W6. 停用 HA 连接**，同第 9 项。
