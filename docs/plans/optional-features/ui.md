# MenuBarHome 面板与设置重构设计 v2

## 修订摘要

- 面板优先显示常用设备与需要处理的提醒。设置统一为五页，日常操作用「连接」「功能」「设备类型」，技术参数收进各自的高级选项。
- 关闭设备类型会收起入口并削减该类型专属的后台工作。已开启的安全提醒仍读取所需信号。定时、启用的自动化和快捷动作受影响时，先列出影响，再由用户决定是否暂停。
- 全关保留 0.6 秒长按和 10/15 秒撤销。设备高风险写入沿用各端的确认步骤。底栏点名暂不可用的平台，详情可点击并支持键盘。
- 新面板先复用 Classic 与 Liquid Glass 的共享组件。仅 macOS 试行内容自适应高度，Windows 第一阶段保留现有固定高度选项。Classic 退役放到最后单独决定。
- 摄像机助手继续随 App 提供。本轮交付首次看实况时才启动，以及停用摄像机类型时回收。工作包按交付边界拆分，共 20 个，含 1 个有条件的收尾包。仅规划交付。

依据为 `rulings.md`、`review-ui.md` 与同目录架构方案，基线为 `936b6f03`。架构依赖以下文的能力名称为准。

## 1. 面板与设置结构

- **快捷面板**　家庭名称、温湿度、搜索与设置 → 置顶提醒与普通提醒条 → 按需输入栏和快捷场景 → 房间及设备类型 → 设备磁贴 → 连接状态、全关和撤销。排序与布局设置放入家庭菜单，入口保留键盘路径。
- **常规**　外观、语言、温度单位、标题和读数、启动和快捷键、设备可见性。高级显示选项按平台呈现。
- **家居连接**　各连接的状态、添加、重连、配置与移除。示例家庭作为体验入口。技术选项收在对应连接卡内。
- **功能管理**　连接开关、设备类型和可选功能。已关闭功能可从搜索和深链原地恢复。
- **安全与提醒**　锁屏控制、提醒、全关范围、高风险控制权限。设备类型关闭后仍可管理对应提醒。
- **关于与诊断**　更新、隐私、排障、重置与退出。全局「查找设置」跨五页定位。

## 2. 首次引导

**入口判定。** 确认无旧设置、凭据或数据痕迹的新安装进入引导。以既有设置标记为主，凭据和数据为辅，分别判断「已配置」和「已连接」。旧用户离线进入面板状态卡，可继续设置或重连。身份读取失败或判定不确定时沿用旧启动逻辑，保留输入和原行为，版本化迁移可重试且未核验时禁止写成功标记。macOS 持久化迁移及清理采用读、合并、写回，冲突留诊断。保留旧用户连接、主题、收藏、房间、排序、快捷键、授权和定时作用域。

1. **选平台**　「你家用哪个平台管理智能设备？」米家、Home Assistant、「先逛逛（不连接设备）」三张卡。首屏只用第三张卡进入示例家庭，连接方式页提供一个跳过入口。完成第一条连接后可添加另一平台，支持双源。
2. **选方式**　米家使用手机 App 扫码，按需展开地区。扫码前以 ≥12pt 警示色提示「使用非官方连接方式。小米可能限制请求或风控账号，登录会过期，到期需重新扫码。凭据安全保存在本机。」HA 提供「查找家中的 Home Assistant」与「手动输入地址」。只有进入 HA 并主动选查找才开始扫描，离开即取消。常显「没找到？在 Home Assistant 网页设置里查看地址」，扫描失败也能手填。未选择连接时无自动扫描、登录、轮询或权限请求。
3. **连接并验证**　米家展示扫码、手机确认、同步状态，二维码超时可原地刷新。HA 展示地址、钥匙、取钥匙指引和「连接并验证」。明文连接沿用当前单独同意，说明钥匙可能以明文传送。失败保留草稿，给出原因、影响、动作，例如「无法访问此地址。设备还未同步。请确认电脑和家庭服务器在同一网络，或修改地址。」可返回或改用示例家庭。
4. **选设备类型与功能**　同步成功后显示实际房间、设备数和可用类型。建议新装默认展示所有已支持类型，并提供「只用灯和开关」与自选，默认待拍板。明确提示「为了继续提供你已开启的安全提醒，仍会读取部分传感器、门锁、阀门、插座和空调的数据。可在『安全与提醒』单独关闭提醒。」只开放已经完成后台裁剪及安全验证的类型。开机启动、安全提醒按本端实际默认显示，AI/语音/外部联动按需开启。
5. **完成**　图示菜单栏或托盘图标。教用户用磁贴左侧开关、右侧打开调节，以及「按住『全关』0.6 秒确认，可在 10 秒内撤销，3 台起为 15 秒」。演练仍走现有只预览路径。引导、检查卡及按钮方位随面板切片同步校对。

先交付选平台、连接、示例家庭和完成页。设备类型裁剪就绪后接入第 4 步。阶段间继续使用现有设备可见性设置。跳过与连接失败可返回，示例态固定显示「示例家庭，不会控制真实设备」，真实连接成功才撤下继续设置卡。

## 3. 功能管理与启停

**列表。** 默认「全部内置功能」，可切换「仅看已启用」。上区为已启用的连接、设备类型汇总和可选功能，下区为可启用或不可用的内置项。每行含图标、名称、一句作用、真实状态/在用摘要、相关设置入口和开关。类型汇总可展开，可用性、原因与动作常显。不设第三方代码插件或插件市场。

| 行状态 | 呈现与动作 |
| --- | --- |
| 已开启／待用 | 显示真实状态，例如「2 条规则已启用」或「打开摄像机画面时启动」。 |
| 可用／已关闭 | 保留配置。搜索词、旧链接及设置锚点可达，显示「此功能已关闭 · 立即开启」。启用成功后原地显示内容并恢复焦点。 |
| 在用／需要处理 | 常显原因，可查看受影响项。直播中提供「关闭画面并停用」。唯一可用连接提示停用后的可见结果，可切换示例家庭或确认进入未连接状态。 |
| 开启中／正在停止 | 禁止重复提交。获准停用即阻断新任务和写入，回收完成才显示「已关闭」。 |
| 启用失败／停止未完成 | 显示原因与「重试」或配置入口。停止超时显示「还在停止 · 重试」，保持新任务被阻断。 |
| 不可用 | 开关置灰，说明原因和解法。例如「此电脑的系统语音组件暂不支持语音输入。可更新系统组件后重试，或继续用键盘输入。」平台固有缺失明示支持范围。 |

- **引用预检。** 关闭连接、类型或父功能前列出受影响的未执行/错过定时、启用的自动化、快捷动作、明确设备群组及依赖功能，标出将隐藏的收藏等偏好。用户可先编辑目标，或按「暂停这些项并关闭」／「取消」。归属未知或无法安全暂停时，显示阻塞原因和处理入口。宿主提交时复核引用及代次，防止预览过时。暂停保留条目、原目标、来源与时间，重新启用前重验全部目标，过期定时进入错过流程。停用夹有已发命令时保留现有回执和回滚规则。
- **设备类型。** 在合成前裁剪仅被关闭类型消费的读取和处理，保留原设备身份、拓扑与历史，供扫描、诊断和周报按原因归属。区分「你已关闭」「平台暂不可用」「已在原平台隐藏」「尚不支持」。HA 第一阶段主要减少本机处理，网络订阅沿用当前实现。关闭类型后从面板、搜索、AI 目录、导出及控制入口撤下对应服务。其他已开启服务仍按现有规则可用。
- **安全与写入。** 安全提醒开启时继续读取并评估所需信号。类型关闭后，安全信号只流入提醒评估及必要的诊断归属。停止某类提醒在「安全与提醒」操作。双端黄金语料固定断言「关闭传感器类型后漏水告警仍触发」。宿主在实体写入前统一拒绝不可用目标并保证零写入，区分「该设备类型已关闭」和「设备不存在」。连接停用也应明确说明。缓存、迟到回调、快捷键、AI、定时及旧链接不能绕过。门锁、阀门、加热及位置未知盖帘沿用设备专属确认，确认与锁屏策略由宿主管理。
- **手动场景和脚本。** 已可用的平台场景和脚本可由用户手动执行。启用类型裁剪时提示「可能控制已隐藏的设备」。保留场景栏、现有执行确认和高风险语义。定时或规则引用按预检处理。场景目标提取留出本轮范围。
- **移除连接。** 从暂停连接的管理入口进入行内两步。「移除本机保存的钥匙与连接信息。用电和温湿度历史会保留。」配「取消」「确认移除」。展开详情显示对应地址、明文同意、连接缓存和临时流密钥，以及原平台撤权指引。暂停完成后仅清该连接的凭据槽和独占数据，共享项最后一位使用者移除时才清。保留作品、历史及重绑所需引用。清理失败显示「未完成移除 · 重试」，继续阻止该连接启动。
- **摄像机。** 内置助手继续随 App 提供，打开实况时懒启动。停用摄像机类型撤销帧任务、保温、子进程和 UDP，其他连接继续。画面不可用显示原因和可执行动作，其他控制可用。普通关窗沿用现有保温，显式停用完成后实况相关后台计数为零。

## 4. 快捷面板与平台差异

- **设备。** 默认双列分体磁贴，左侧开关、右侧调节。仅有一种动作的磁贴保留相应入口。常用、收藏和已开启优先。超过 8 台时，可在全部视图展开长尾或按房间找。离线和未通电设备收起抽屉、沉底，保留既有隐藏偏好。高风险动作仍经确认。
- **提醒。** 烟雾、燃气、漏水、门铃、错过的定时各用独立卡置顶。设置页的普通通知收纳选项不作用于这些卡片。门窗、人体、门锁、震动在各端支持且对应提醒开启时置顶，沿用离开条件。高功率与长开逐条处理。只有离线、低电量等普通提醒进入 32pt 胶囊并可一键收起。门铃有画面便提供「查看画面」，摄像机类型关闭时提示如何重新启用，提醒仍可见。错过的定时沿用「立即执行」「忽略」及执行前重验。
- **全关。** 保留 0.6 秒长按、释放或失焦/隐藏解除待确认、现有参与范围和默认排除提示（如插座、扫地机）。撤销横幅 1–2 台 10 秒，3 台起 15 秒，按现有事务与匹配规则撤销。原参与范围可查看，类型关闭的设备不进入本次目标。键盘沿用本端等效安全操作，普通回车和双击不能跳过确认。
- **键盘。** 面板内沿用直接输入搜索、数字切房间与方向键导航，不抢表单输入。Escape 先处理当前确认或活动长按，再收起抽屉、提醒列表或连接详情，最后退出搜索/面板。面板隐藏时清待确认与临时态。浮层用键盘可达并在关闭后归还焦点。
- **macOS。** 先提取 Classic 与 Liquid Glass 可共用的提醒、状态及磁贴。保持 Classic 默认和 macOS 14/15 支持，新交互在现有实现上渐进落地。仅在试点路径按 380pt 宽、约 280–560pt 高量测，受可用屏幕高度限制并在设备区内部滚动。由窗口控制器串行管理尺寸与重定位，回放开合、切房间/抽屉和多屏。重标定 GrokBall 球体锚点、展开浮层评分、翻转及裁切，快照覆盖展开态。试点保留现有 Classic 高度及回退路径。
- **Windows。** 第一阶段共享布局结构、提醒与文案，保留固定高度档 580/680/780px 及现有「最大」档、412×680 默认窗和 16px 阴影留白。保留任务栏边缘吸附、钉住、位置偏好、失焦行为与 DPI。按平台使用原生窗口材质及「托盘」「Ctrl/Alt」，macOS 用「菜单栏」「⌘/⌥」。设备高风险确认保留卡片/抽屉上的现有专属确认步骤，详见文末。

### 4.1 底栏状态与失败

| 状态 | 文案或处置 |
| --- | --- |
| 全部启用的连接正常 | 「设备同步正常」。状态图标配文字。 |
| 部分不可用 | 点名平台，例如「米家暂不可用，部分设备暂无数据」或「Home Assistant 暂不可用，部分设备暂无数据」。若只剩 LG 在线，显示「米家暂不可用，LG 电视仍可控制」。仅在具体设备有证据时说明可改用的通道。 |
| 单连接故障／全部不可用 | 点名故障平台并提供「查看连接」或「重试连接」。已知是用户主动停用时提示启用入口。 |
| 示例／未连接 | 固定「示例家庭，不会控制真实设备」／「还没连接家居平台」，后者可「去连接」。 |
| 首次拉取／刷新 | 首次骨架加状态说明，Web 使用 `aria-busy`。刷新保留旧列表并标示正在同步，过期数据显式说明。 |

| 表单未保存／保存失败 | HA 地址或钥匙、AI 密钥关闭或切页前提示「保存更改／放弃更改／取消」。保存失败保留草稿、未保存状态和焦点，错误脱敏。 |

### 4.2 视觉与可访问性验收

- 沿用现有系统材质、浅深色语义和原生焦点。设备/设置行标题约 13pt，帮助 ≥11pt，非官方连接、明文、免确认和其他风险 ≥12pt 并用主色或琥珀警示色。正常文本在实际浅/深色背景上测 ≥4.5:1。在线、未配置、需重登、断连用形状加文字区分。
- 磁贴、开关、图标按钮有可读名称和可见焦点，纯图标同时提供提示。可交互热区至少 28×28pt 等效。Tab 顺序符合视觉顺序，真正模态才圈定焦点。恢复行、错误提示、详情和高风险确认可被读屏辨识。
- 检查 200% 文本、360px 等效窄宽、三语长标签、减弱动态、减少透明度和增强对比度。内容折行，无横向溢出。减少透明度改用实色和边界，键盘搜索即时响应，收起窗口清除动画及待确认态。

- 「保持现有独立确认、不行内化」如果要求 Windows 改为卡片外确认，会改变既有形态。基线 `windows/src/ui/deviceViews.ts:103–117,319–322` 的专属「确认执行」按钮已挂在设备卡片/抽屉内，`windows/src/ui/bindEvents.ts:783–798` 在明确点击后校验期限、来源代次和当前设备，才执行命令。实施按独立确认**步骤**理解，保留 Windows 挂载点与保护，macOS 继续使用现有独立对话。
